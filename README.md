how to build code

1. install Opencad from https://openscad.org/
2. paste code in editor 
3. hit F5 button to view look for error
4. hit F6 to build 3D or 2D drawing save file xxxx.scad
5. Meny File --> Export --> 
Export to xxxx.stl (Ascii or Bin) or xxx.dxf ect.
